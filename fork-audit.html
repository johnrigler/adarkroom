What this audit can and cannot establish

GitHub timestamps and stars do not prove that a fork contains useful work. This page first ranks likely candidates, then asks GitHub to compare each candidate against the upstream default branch. A positive ahead_by value establishes that the fork has commits not present upstream.

Identity signals are keyword matches in changed filenames, patches, and commit messages. They are leads, not proof of a self-sovereign identity implementation. The unauthenticated API limit prevents comparing every fork in a large network in one pass.

The page sends no credentials and stores nothing. It can be served from IPFS or opened as a local file, but the live audit still depends on GitHub's public API.
